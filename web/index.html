UAIMS PAF‑IAST Inventory & Office Management

A desktop inventory system, built and verified end‑to‑end.

UAIMS tracks stationery stock, teachers, issue/return records, printing jobs, documents, suppliers, and purchase orders for a university office — running here against a local SQLite database seeded with real demo data, not a mockup.

Sign-in — bcrypt auth, forced password change on first login
Dashboard, logged in as Store Keeper — live counts from the seeded database (100 items, 3 low‑stock alerts)

Why this page isn't on vercel.com: UAIMS is a native desktop application (PySide6/Qt), not a website — it opens its own window and reads a local SQLite file on disk. Vercel hosts web apps: static pages and serverless functions running in a browser. There's no version of a Qt window that runs inside one, so there's nothing here for Vercel to deploy.

This page is the fast, honest alternative: a real, live link you can share right now, pointing at real screenshots and real build artifacts. Turning UAIMS itself into a website would mean rebuilding it as a web app with a hosted database — a new project, not a deployment step.

Run from source

Quick start

Needs Python 3.11+. On Debian/Ubuntu, the venv below is required — system pip refuses global installs (PEP 668).

# clone, create a virtual environment, install, run
git clone git@github.com:AhmedSaleemKhan/uni-inventory-system-.git
cd uni-inventory-system-
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python main.py

What it does

Twelve modules, one office

Inventory

Barcode + QR generation, low/out-of-stock detection, category filters.

Issue & return

Stock validation on issue, overdue detection and auto-restock on return.

Printing jobs

B/W and color, single/double-side, automatic cost calculation.

Documents

Lifecycle tracking: Pending → Received → Approved / Rejected.

Suppliers & purchases

Multi-line purchase orders with tax calculation and stock receipt.

Reports

Nine report types, each exportable to PDF, Excel, and CSV.

Roles

Six roles with a declared permission matrix, enforced on every page.

Audit trail

Every login, save, and delete is logged with the acting user.

Backups

Automatic snapshot on launch, plus manual backup/restore/export.

Under the hood

Stack

UI
PySide6 (Qt for Python) — native desktop window, light/dark theme
Data
SQLAlchemy 2.x ORM over SQLite, foreign keys enforced
Auth
bcrypt password hashing, login history, audit log
Reports
ReportLab (PDF), OpenPyXL (Excel), csv (built-in)
Codes
qrcode + python-barcode + Pillow
Charts
Matplotlib, embedded via a Qt canvas
Packaging
PyInstaller, built per-OS by GitHub Actions
